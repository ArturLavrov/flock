## 🕊️ Overview

**Flock** is a decentralized service discovery framework built with Go.  
It leverage a gossip-like algorithms (SWIM) to provider information about cluster node membershipe without relying on a central registry.

Flock can serve as a servide discovery foundation for building resiliance mission critical microservice/service oriented stems
